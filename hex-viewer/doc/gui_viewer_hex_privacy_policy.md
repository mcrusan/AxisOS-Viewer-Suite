# **AxisOS Viewer Suite — Privacy Policy (v1.3)**  
**Effective Date:** Upon release  
**Application:** AxisOS Viewer Suite (CRUSAN)

## **Overview**  
The AxisOS Viewer Suite is a local, offline binary inspection tool.  
It does **not** collect, store, transmit, or share any personal data.

## **Data Collection**  
The application does **not** collect any of the following:

- Personal information  
- Contact information  
- Usage analytics  
- Device identifiers  
- Location data  
- Network data  
- Telemetry of any kind  

The Viewer Suite operates entirely on the user’s device and does not communicate with external servers.

## **File Access**  
The application only accesses files that the user explicitly selects through the **Open File** dialog.  
Files are processed **locally in memory** and are never uploaded, transmitted, or shared.

## **Plugins**  
Plugins loaded by the user run locally and follow the same privacy model:  
no data collection, no network transmission, no external communication.

## **Third‑Party Services**  
The application does **not** use any third‑party analytics, tracking libraries, or cloud services.

## **Children’s Privacy**  
The application does not target children and does not collect any data from users of any age.

## **Changes to This Policy**  
If the privacy model ever changes, this policy will be updated and included with the application.

## **Contact**  
For questions about this policy, contact the AxisOS micro‑enterprise maintainer.
